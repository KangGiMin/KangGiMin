
# 👤 About Me  

<br>

✅ 웹 서비스의 기능을 설계하고 구현하는 데 관심을 가진 주니어 풀스택 개발자입니다.
<br>
<br>
✅ 대학 동아리 및 국비 지원 부트캠프 훈련 과정에서 **일정 수정 API를 구현하고 프론트엔드와 연동** 경험과 <br>웹 커뮤니티 플랫폼에서의 게시글 및 댓글 CRUD 구현 경험 등과 같은 <br>서버와 클라이언트 사이의 데이터 흐름을 이해하고 기능을 완성하는 경험을 쌓았습니다.
<br>
<br>
✅ 단순한 기능 구현에 그치지 않고 코드의 동작 원리를 이해하며, 유지 보수하기 좋은 코드와 명확한 문서화를 중요하게 생각합니다.
<br>
<br>
✅ 현재는 실전 프로젝트를 통해 개발 역량을 넓히고, 사용자에게 실제로 많은 도움이 되는 웹 서비스를 구현하는 것을 목표로 하고 있습니다.

<br>
